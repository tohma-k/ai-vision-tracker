# AI Vision Tracker

Real-time AI-powered object tracking system using YOLOv8 and OpenCV.

## Features

- Real-time object detection
- Webcam video processing
- Bounding box tracking
- Target center calculation
- FPS monitoring

## Tech Stack

- Python
- OpenCV
- YOLOv8
- Ultralytics

## Installation

```bash
pip install -r requirements.txt
```

## Run

```bash
python src/main.py
```
